Design tokens & three directions

I built a token system from the fonts, colours, sizes and effects the live CSS already uses, and fixed the variables that are broken. On top of it are three directions. C · Blend is the current recommendation: Refine's teal system, Fresh's typography, and coral as teal's complementary accent. All three restyle only through CSS layered after the existing stylesheets, so the HTML and page structure stay the same.

What the current CSS does

Type

  • There are two scales. main.css uses fixed sizes (.75, 1, 1.5, 2rem) and typographies.css uses fluid clamp() sizes. Because the hero h1 uses the 2rem one, it renders at 32px while each h2 is 43px.
  • Body line-height is set to var(--font-size-h4), a size variable rather than a line-height.
  • The intro paragraphs are wrapped in <strong>, so the whole block is bold. Prose lines run to about 120 characters.
  • Raleway uses old-style figures by default, which makes +48 668 093 234 look uneven.

Colour

  • White on the brand teal #018E87 is 4.0:1, below the AA minimum for normal text. That covers the buttons, CTA bar and top bar.
  • The white "Artykuły i Baza Wiedzy" heading on #66CCC7 is 1.9:1.
  • Colours are hard-coded outside the variables: #333, #cacaca, #fff, and on sub-pages two more teals (#3FA299, #3F8378).

Shape, space, effects

  • Four variables are used but never defined: --space-small, --border-radius-small and --font-size-h6. --border-radius-circle: var(50%) is invalid.
  • Service cards are square-cornered, while panels use 2rem corners and the pills are fully rounded.
  • The two-sided "neumorphic" shadow on a grey page makes the cards look hazy. On hover, cards grow to 1.1× and fill with teal.
  • Stray values sit outside the spacing scale: 30px, 4rem, 6rem, and 1310px next to 80rem.

Palette for C · Blend

Teal is the primary colour and coral is its complement, kept for booking. The four tertiaries fill the rest of the colour wheel: ochre, sage, berry and a soft sky blue. Each family has three steps. Soft is a background tint, base is a fill that takes dark ink text, and strong is for text and outlines on white or on its own soft tint. Every combination shown passes WCAG AA. Tertiaries are for sorting and labelling: categories, badges, filters and illustration accents. They are not for buttons, so teal and coral keep their meaning. The suggested uses follow the site's own categories.

What the component layer changes

Hero

  • The h1 uses --font-size-h1, so it is the largest heading on the page again.
  • The flat 50% black overlay and blur become a bottom-weighted scrim, so the photo stays visible and the text stays readable.
  • Buttons become pills with a darker hover and a visible focus ring.

Content & services

  • Prose is capped at a comfortable line length, and the <strong> wrapper is neutralised with CSS.
  • Cards get rounded corners, a hairline border and a soft shadow. Hover lifts a card 4px and turns the title teal/indigo instead of filling the whole card.

Knowledge base, CTA, footer

  • The band becomes a pale tint with a dark heading (1.9:1 becomes 7:1 or more).
  • Chips fill with the brand colour on hover and focus.
  • The CTA bar uses --clr-base-strong and the footer uses a deep brand neutral instead of #444.
  • Hover movement is switched off when the visitor has prefers-reduced-motion set.

Applying it to the live site

  1. Pick a direction and add one stylesheet after tables.css: <link rel="stylesheet" href="/css/tokens.refine.css">. Each file holds the tokens and the component layer.
  2. Optional clean-up: move the typographies.css scale into the token file and delete the duplicate p, li, td… block from main.css.
  3. Content fixes outside CSS: the link text "Wszystkie arytkuły" has a typo, and the empty psyche-video.webm on the server is 0 bytes, so browsers have to fall back to the MP4.
